Guide de modification

Les étapes simples pour ajouter ou changer une fonctionnalité dans cette application Django.

Ajouter une nouvelle fonctionnalité

  1. Créer ou modifier un modèle dans store/models.py.
  2. Créer un formulaire dans store/forms.py.
  3. Ajouter les vues dans store/views.py.
  4. Déclarer les routes dans store/urls.py.
  5. Créer les pages HTML dans templates/store/.
  6. Lancer python manage.py makemigrations puis python manage.py migrate.
  7. Vérifier avec python manage.py check.

Ajouter ou changer un thème

  1. Ajouter le nom du thème dans StoreSettings.THEME_CHOICES.
  2. Ajouter les couleurs CSS dans templates/store/base.html.
  3. Utiliser une classe comme body.theme-nom.
  4. Aller dans Paramètres et choisir le nouveau thème.

Modifier une facture

  1. Modifier l'affichage imprimable dans templates/store/sale_invoice.html.
  2. Modifier le PDF dans sale_invoice_pdf dans store/views.py.
  3. Ajouter une option dans StoreSettings.INVOICE_LAYOUT_CHOICES si nécessaire.
  4. Tester une vente, puis ouvrir Facture et PDF.

Exemple de note de code

Fonction: Remise sur vente
Modèle: ajouter discount dans Sale
Vue: calculer total après remise
Template: afficher remise sur sale_detail.html
Migration: makemigrations + migrate
